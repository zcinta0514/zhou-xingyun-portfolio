# Portfolio Pen

网站自我介绍专用字体子集，来源：[YShi-Written / 写意体](https://github.com/Steve-Yuu/YShi-Written)，上游文件 `font/YShiWrittenSC-Regular.ttf`。

基于开源硬笔手写字形，字体按 SIL OFL 1.1 分发，原授权全文见 OFL.txt。为遵守上游保留名称要求，本站子集重命名为 Portfolio Pen。

2026-09-26 使用 FontTools 提取原首页四段介绍的字形并编码为 WOFF2，未修改轮廓。全部当前字符已核对覆盖；如果修改介绍，应重新生成子集，否则新字会回退到系统字体。仅用于网页真实文字，不是图片或整套新字库。
